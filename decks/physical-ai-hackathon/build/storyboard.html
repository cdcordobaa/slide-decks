▸ Fast models on every frame, the language model only on events, and every model on the box.

speaker notes · facts
Say: Everything runs on one Jetson Thor; the browser only draws. It senses with a simulated camera, a radiometric thermal camera and a 3D lidar; perception turns that into facts; the brain decides ten times a second, a human approves, and the legs and arms act at 50. The language model sits beside the loop: it pulls one frame when asked. With every feature on, the simulation holds real time. Our hardest performance problem was not the Thor: the same file moves at 311 megabytes a second on the box and 165 kilobytes through the tunnel, so we send only what changed.
